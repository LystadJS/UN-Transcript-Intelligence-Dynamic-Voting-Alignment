# README visual assets

[← Project overview](../../README.md)

| Asset | Source and treatment |
|---|---|
| `project-banner.svg` | Original vector layout for this repository. Navy, ivory, gold, and UN-blue accents; no remote fonts, scripts, or external image dependencies. The emblem is embedded from `un-emblem.svg` with its original color and proportions. |
| `un-emblem.svg` | [Emblem of the United Nations, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Emblem_of_the_United_Nations.svg), credited there to Joowwww with later contributor revisions. Downloaded unchanged on 2026-09-22 from the [original SVG URL](https://upload.wikimedia.org/wikipedia/commons/5/52/Emblem_of_the_United_Nations.svg). Commons records a public-domain dedication; insignia-use restrictions are separate from copyright. |
| `briefing-showcase.png` | A documentation-only composition of the repository's actual `examples/email-preview.html` and `examples/drift-demo/model-assets/statements/movement.png`. The briefing is an excerpt; the map is a visibly labeled synthetic engineering fixture. |

The emblem identifies the research subject. These assets do not assert UN,
USUN, or State Department sponsorship or endorsement. The report itself does
not acquire institutional branding from this README redesign.

The root `release-index.json` remains the manifest of the frozen 0.2.0 release
bundle. It predates this documentation redesign; Git history records subsequent
README and documentation asset changes.
