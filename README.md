## Overview

This repository is reserved for a project concerning **UN transcript intelligence and dynamic voting alignment**. The repository is intentionally public at an early stage so the project has a stable location, but substantive data, methodology, code, and results have not yet been released here.

Accordingly, this README does **not** claim that a finished analytical pipeline or empirical result currently exists in the repository.

## Publication standard

As work is published, this repository will document the project in the following order:

1. **Research question** — the substantive question and unit of analysis.
2. **Data provenance** — source institutions, retrieval dates, coverage, licensing, and exclusions.
3. **Methodology** — transcript processing, feature construction, alignment measures, statistical models, and validation.
4. **Reproducibility** — environment requirements, deterministic steps, random seeds, and execution order.
5. **Results** — figures, tables, uncertainty, robustness checks, and limitations.
6. **Citation** — versioned citation guidance for both code and underlying data.

## Planned repository structure

The structure below is a presentation standard, not a claim that these directories already exist:

```text
README.md          project status and methodological overview
data/               only data that may be redistributed
scripts/           ingestion, cleaning, analysis, and validation
src/               reusable project code
notebooks/         bounded exploratory work, if needed
outputs/           generated tables and figures
docs/              methodology, data notes, and decision logs
```
